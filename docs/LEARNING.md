# คู่มือเรียนรู้ระบบคำนวณค่าใช้จ่ายเดินทางไปราชการ (สำหรับผู้เริ่มต้นจาก 0)

## ภาพรวม: เว็บนี้ทำงานยังไง

เว็บนี้เป็น **หน้าเว็บธรรมดา** (ไม่มีขั้นตอน "build" หรือ "compile" ใดๆ) เปิดไฟล์ `index.html`
ในเบราว์เซอร์ก็ใช้งานได้เลย ประกอบด้วย 3 ส่วน:

1. **HTML** (`index.html`) — โครงหน้าตาเว็บ (มีอะไรบ้าง อยู่ตรงไหนบ้าง)
2. **CSS** (`css/style.css`) — สีสัน ระยะห่าง ธีมของเว็บ
3. **JavaScript** (`js/*.js`) — ตรรกะการทำงาน (กดปุ่มแล้วเกิดอะไรขึ้น, ดึงข้อมูลจากฐานข้อมูล)

ข้อมูลทั้งหมด (ทริป, ผู้เดินทาง, อัตราค่าใช้จ่าย) เก็บอยู่ที่ **Supabase** ซึ่งเป็นบริการฐานข้อมูล
ออนไลน์ฟรี (ใช้ตัวเดียวกับที่ใช้ในระบบเงินเดือน แต่เป็นคนละโปรเจกต์กัน แยกข้อมูลกันเด็ดขาด)

## ทำไมระบบนี้ไม่มีปุ่ม "สมัครสมาชิก"

ต่างจากระบบเงินเดือนที่เปิดให้ทุกคนสมัครเองแล้วรอแอดมินอนุมัติ ระบบนี้คุณขอให้ **จำกัดเฉพาะแอดมิน**
เข้าใช้งาน จึงไม่มีหน้าสมัครสมาชิกเลย การสร้างบัญชีผู้ใช้ต้องทำผ่าน **Supabase Dashboard**
โดยตรง (ขั้นตอนด้านล่าง) ซึ่งปลอดภัยกว่าเพราะไม่มีใครเข้าเว็บมากดสมัครเองได้

## ขั้นตอนสร้างบัญชีแอดมินคนแรก

1. เข้า [supabase.com](https://supabase.com) → ล็อกอิน → เลือกโปรเจกต์ **travel-expense-app**
2. ไปที่เมนู **Authentication → Users** ทางซ้าย
3. กดปุ่ม **Add user** → **Create new user**
4. กรอกอีเมลและรหัสผ่านที่ต้องการ แล้วติ๊ก **Auto Confirm User** (สำคัญ! ไม่ติ๊กจะล็อกอินไม่ได้
   เพราะเว็บไม่มีระบบส่งอีเมลยืนยัน)
5. กด **Create user**
6. ระบบจะสร้างบัญชีขึ้นเป็นเจ้าหน้าที่ทั่วไป (officer) โดยอัตโนมัติ — บอกผมว่าสร้างเสร็จแล้ว
   ผมจะช่วยปรับสิทธิ์บัญชีนี้ให้เป็น "แอดมิน" ให้อีกที (ต้องทำผ่านฐานข้อมูลโดยตรง เพราะบัญชีแรกยัง
   ไม่มีใครเป็นแอดมินที่จะเข้าไปกดปุ่มเปลี่ยนสิทธิ์ให้ตัวเองได้)

## วิธีทดสอบเว็บบนเครื่องตัวเอง

1. ดาวน์โหลดโค้ดทั้งหมดจาก GitHub (ปุ่ม Code → Download ZIP) แล้วแตกไฟล์
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก หรือลาก์เข้าเบราว์เซอร์)
3. ล็อกอินด้วยบัญชีที่สร้างไว้ในขั้นตอนก่อนหน้า

## คำศัพท์ที่เจอในโค้ด (แปลง่ายๆ)

- **RLS (Row Level Security)** — กฎในฐานข้อมูลที่กำหนดว่า "ใครเห็น/แก้ข้อมูลไหนได้บ้าง" เป็นเกราะ
  ป้องกันจริง ไม่ใช่แค่ซ่อนปุ่มบนเว็บ (ต่อให้เปิด developer tools ก็ยังถูกฐานข้อมูลปฏิเสธ)
- **effective_date** (อัตราค่าใช้จ่าย) — วันที่อัตรานั้นเริ่มมีผล ใช้แทนการ "แก้ตัวเลขเดิม" เพื่อไม่ให้
  ทริปเก่ากระทบเวลาอัตราเปลี่ยนในอนาคต
- **trip / trip_members** — ทริป 1 ทริปอาจมีผู้เดินทางหลายคน (หมู่คณะ) แต่ละคนคำนวณเบี้ยเลี้ยง/
  ที่พัก/พาหนะแยกกัน แล้วรวมยอดทั้งทริปทีหลัง
