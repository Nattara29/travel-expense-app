# แผนพัฒนาระบบคำนวณค่าใช้จ่ายเดินทางไปราชการ เทศบาลเมืองศรีสัชนาลัย

## เฟส 0 — โครงสร้างพื้นฐาน (เสร็จแล้ว ✅)
- ฐานข้อมูล Supabase: ระดับตำแหน่ง 11 ระดับ, ตารางทริป/ผู้เดินทาง/อัตราค่าใช้จ่าย/ผลคำนวณ, RLS ครบ
- ใส่อัตราจริงตามระเบียบกระทรวงมหาดไทยว่าด้วยค่าใช้จ่ายในการเดินทางไปราชการของเจ้าหน้าที่ท้องถิ่น
  (เบี้ยเลี้ยง, ค่าที่พักจ่ายจริง/เหมาจ่าย, ค่าพาหนะส่วนตัว) — แก้ไขอัตราในอนาคตได้ผ่านเมนูแอดมิน
  โดยไม่ลบของเดิม (เก็บประวัติด้วย effective_date)
- โครงหน้าเว็บ (sidebar/topbar), ธีมสีฟ้า/ม่วง/ส้ม/ทอง ตามภาพอ้างอิง
- **ผู้ใช้งานทั่วไปเข้าหน้าเว็บและใช้เครื่องคำนวณได้ทันทีโดยไม่ต้องล็อกอิน** (หน้าแรกให้เลือกว่า
  จะคำนวณค่าใช้จ่ายไปราชการหรือไปฝึกอบรม) — ตารางระดับตำแหน่ง/อัตราค่าใช้จ่ายเปิดอ่านสาธารณะไว้
  เพื่อให้เครื่องคำนวณทำงานได้โดยไม่ต้องมีบัญชี
- **ผู้ดูแลระบบ**กดปุ่ม "เข้าสู่ระบบผู้ดูแลระบบ" มุมขวาบนเพื่อล็อกอิน (กล่องโต้ตอบเล็กๆ ไม่ใช่หน้าแยก)
  จะเห็นเมนูเพิ่ม "แดชบอร์ด" และ "จัดการอัตราค่าใช้จ่าย" — **ไม่เปิดสมัครสมาชิกเอง** บัญชีสร้างผ่าน
  Supabase Dashboard โดยแอดมินเท่านั้น
- แดชบอร์ดสรุปตัวเลขเบื้องต้น (ยังไม่มีข้อมูลจริง เพราะยังไม่มีทริปถูกสร้าง)

## เฟส 1 — คำนวณค่าใช้จ่ายเดินทาง (ไปราชการเสร็จแล้ว ✅ / ไปฝึกอบรมยังไม่ได้ทำ ❌)
เมนู "คำนวณค่าใช้จ่ายเดินทางไปราชการ" มีเมนูย่อยแบบกาง/หุบ (accordion) ในแถบเมนูด้านซ้าย:
1. **ค่าเบี้ยเลี้ยง (คนเดียว/หมู่คณะ)** ✅ — เลือกระดับตำแหน่ง, กรอกวันเวลาออก-กลับ, ติ๊กว่ามีการพักแรม
   หรือไม่ คำนวณจำนวนวันอัตโนมัติตามข้อ 17 ของระเบียบ (พักแรม: 24 ชม./วัน เศษเกิน 12 ชม.นับเพิ่ม 1 วัน
   / ไม่พักแรม: เกิน 12 ชม.=1 วัน, เกิน 6-12 ชม.=ครึ่งวัน) แบบหมู่คณะเพิ่มได้หลายคน แต่ละคนเลือกระดับ
   ตำแหน่งเองได้ ใช้กำหนดการเดินทางเดียวกันทั้งคณะ
2. **ค่าที่พัก (คนเดียว/หมู่คณะ)** ✅ — เลือกจ่ายจริง (มีเพดานตามระดับตำแหน่ง+ประเภทห้อง ระบบหักไม่ให้
   เกินเพดานอัตโนมัติ) หรือเหมาจ่าย (ตัวเลขคงที่) แบบหมู่คณะแต่ละคนเลือกห้องเดี่ยว/คู่เองได้
3. **ค่าพาหนะ** ✅ — พาหนะส่วนตัว (รถยนต์/รถจักรยานยนต์) คิดตามระยะทาง กม. × อัตรา
4. **บันทึกเป็นทริปในระบบ/ส่งขออนุมัติ** ❌ — ตอนนี้เป็นเครื่องคำนวณอย่างเดียว (คำนวณแล้วแสดงผลทันที
   ไม่ได้บันทึกลงฐานข้อมูล) เพราะผู้ใช้งานทั่วไปไม่ได้ล็อกอิน ไม่มีบัญชีให้ผูกกับทริป — การบันทึกเป็น
   ทริปทางการ + ระบบอนุมัติ จะทำในเฟส 3
5. เมนู "คำนวณค่าใช้จ่ายเดินทางไปฝึกอบรม" — ยังไม่ได้ทำ จะใช้ตรรกะเดียวกับข้างต้น (ต่างกันแค่ประเภททริป)

## เฟส 2 — จัดการอัตราค่าใช้จ่าย (ยังไม่ได้ทำ ❌)
- เมนู "จัดการอัตราค่าใช้จ่าย" (แอดมินเท่านั้น) — ดูอัตราปัจจุบันทุกประเภท, เพิ่มอัตราใหม่พร้อมวันที่เริ่มมีผล

## เฟส 3 — เอกสาร/อนุมัติ/พิมพ์ (ยังไม่ได้ทำ ❌)
- แนบเอกสารอ้างอิง (คำสั่ง/หนังสืออนุมัติ) เข้ากับทริป
- ระบบอนุมัติ (draft → pending → approved/rejected)
- พิมพ์/ดาวน์โหลด PDF ใบสรุปค่าใช้จ่ายเดินทาง

## เฟส 4 — เตรียมใช้งานจริง (ยังไม่ได้ทำ ❌)
- ตั้งค่า GitHub Pages
- สร้างบัญชีแอดมินจริงผ่าน Supabase Dashboard + ตั้ง role เป็น admin
- ทดสอบกับการเดินทางจริง
