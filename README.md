# ระบบคำนวณค่าใช้จ่ายเดินทางไปราชการ/ฝึกอบรม

ระบบคำนวณเบี้ยเลี้ยง ค่าที่พัก และค่าพาหนะ สำหรับการเดินทางไปราชการและไปฝึกอบรม
ของเทศบาลเมืองศรีสัชนาลัย รองรับการคำนวณทั้งแบบรายบุคคลและแบบหมู่คณะ
ตามระเบียบกระทรวงมหาดไทยว่าด้วยค่าใช้จ่ายในการเดินทางไปราชการของเจ้าหน้าที่ท้องถิ่น
